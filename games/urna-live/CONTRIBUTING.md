# Como contribuir

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie um fork e uma branch para sua mudança.
3. Faça alterações pequenas e verificáveis; mantenha os commits em português, se possível.
4. Teste a interface, a animação das mãos, o painel e o reconhecimento de presentes.
5. Envie um pull request explicando o que mudou e como testar.

Não inclua tokens, credenciais, dados pessoais ou imagens sem permissão de redistribuição.
